================================================================================
                            FILE SIZE CALCULATION
================================================================================

Estimate Rows from File Size:

Formula: Rows ≈ (File Size in MB × 1,000,000) / (Columns × 50)

Example:
  File Size: 10 MB
  Columns:   20
  Rows:      (10 × 1,000,000) / (20 × 50) = 10,000 rows
